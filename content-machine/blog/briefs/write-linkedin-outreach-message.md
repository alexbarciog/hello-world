# Brief: how to write a linkedin outreach message (guides, 2026-10-22)

## Intent
Procedural with a template craving. The searcher wants to send a message today and get a reply. Top results are
long vendor guides (lemlist, Close, Nutshell, PhantomBuster) and template dumps (Taplio 12 templates, Dealsflow
25). Format to match: steps plus copy-paste templates, with a FAQ.

## What every page covers (table stakes)
- Personalise the opener (post, mutual connection, event, job change).
- Keep it short; no pitch in the first message; one small ask, not a meeting.
- Connection request vs direct message vs InMail.
- Follow up 2 to 3 times, 24h+ apart, then stop.
- Profile must be presentable before messaging.

## What no page covers (the gap)
- None starts from the signal. All of them start from a list and personalise after the fact ("mention a post").
  Nobody says: find the thing the person did this week, and write the message about that.
- None gives a character budget per line, so readers cannot tell a 180-character note from a 600-character one.
- None gives a filled, dated sequence with the signal carried through all three messages.
- Numbers are unsourced (Nutshell reply rates "6 to 7%", no source) or recruiting data presented as sales data.
  The one primary source found (LinkedIn's own InMail data, May 2021 to April 2022, recruiter InMails) is
  usable if labelled as recruiter data.
- Limits conflict: Hublead says the connection note is 200 characters citing LinkedIn Help; QuickMail says 300.
  LinkedIn Help pages could not be opened from this run (robots). The guide tells the reader to trust the
  counter in the invite box and keeps every template under 200 characters so it fits either way.
- No "where this goes wrong" with the actual failure modes (fake compliment, two asks, pitch in the note,
  follow-up that says "just checking in").

## Unlike the pages ranking now, this one ...
... builds the message from one LinkedIn signal (a post the person engaged with, a post they wrote, a hire,
a job change) instead of from a list, gives a four-line structure with a character budget for each line,
fills the whole three-message sequence for one labelled hypothetical company with the days between messages,
quotes LinkedIn's own length data with its caveat, states the daily caps we actually run (15 a day, 30 max),
and ends with a ten-point check the reader runs before pressing send.
