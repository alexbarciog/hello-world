# Brief: how to set up linkedin sales navigator alerts (guides, 2026-10-30)

## Intent
Procedural. The searcher has (or is trialling) Sales Navigator, sees an empty or noisy Alerts feed, and wants
the clicks that make alerts fire for the right people and arrive in the right place. The top results are
vendor blog posts shaped as "what alerts are / where to find them / types / how to set up / how to use".
